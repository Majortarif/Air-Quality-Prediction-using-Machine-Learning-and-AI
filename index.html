AQI uses US EPA breakpoints on the latest concentrations. For each pollutant the higher of the 2024 and pre-2024 EPA tables is used, so the index is never understated. Official AQI uses 24 h (PM) and 8 h (O3, CO) averages, so treat this as a near-real-time estimate.

Connect my sensor

Send one JSON reading every 30 seconds to a Supabase table (or a ThingSpeak channel), then open Settings, choose "My sensors" and paste the URL and read key. The thesis node used an Arduino UNO, which has no WiFi. For live upload use an ESP32 (or ESP8266) as the controller, or add an ESP module beside the UNO.

2. Supabase table (SQL editor)

The gas conversion functions are placeholders. MQ-7, MQ-131 and the MEMS NO2 module need calibration against a reference instrument before their numbers mean anything. MQ modules output up to 5 V, so use a voltage divider on ESP32 inputs (3.3 V maximum), and use ADC1 pins because ADC2 is unavailable while WiFi is on.

ThingSpeak option

Write the reading to channel fields in this order. In Settings choose ThingSpeak and enter the channel ID and read API key.

  1. field1 = PM2.5 (µg/m³)
  2. field2 = PM10 (µg/m³)
  3. field3 = NO2 (ppb)
  4. field4 = O3 (ppb)
  5. field5 = CO (ppm)
  6. field6 = Temperature (°C)
  7. field7 = Humidity (%)

Security notes

  • Put only the Supabase anon key in the page or device, never the service_role key.
  • Keep Row Level Security on. The SQL above allows public read and insert; for a real deployment restrict inserts to your device (for example through an Edge Function).
  • Keys typed into Settings stay in this browser's localStorage only.
